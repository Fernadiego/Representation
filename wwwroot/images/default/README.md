# Imágenes por Defecto de Productos

Este directorio contiene 5 imágenes por defecto que se mostrarán cuando un producto no tenga una imagen asignada.

## Imágenes requeridas

Las imágenes deben llamarse:
- **default-1.png** - Sillón rosa
- **default-2.png** - Botella blanca
- **default-3.png** - Smartphones
- **default-4.png** - Smartwatch naranja
- **default-5.png** - Zapatillas azules

## Formato
- Las imágenes deben ser circulares o cuadradas
- Se mostrarán en formato circular de aproximadamente 45x45px en la grilla
- Formato recomendado: PNG con fondo transparente o circular

## Comportamiento
Las imágenes serán seleccionadas de manera determinística basada en el ID del producto, por lo que un producto sin imagen siempre mostrará la misma imagen por defecto.
